# CrownWalk

A shoe store web application, built end-to-end as an experiment in **AI-assisted development**: I drove the design, product decisions and custom functionality, and used AI coding tools to implement and iterate on them.


## About the project

CrownWalk is an online storefront for shoes. The goal was twofold:

1. Ship a complete, usable e-commerce experience rather than a tutorial-sized demo.
2. Learn where AI coding tools are strong, where they need steering, and how to review and rework their output with real judgement.

## How it was built

I treated AI as a fast pair programmer rather than an autopilot:

- I defined the design direction, page structure and the custom behaviour I wanted.
- AI tools generated and iterated on code against those requirements.
- I reviewed the output, rewrote the parts that were wrong or over-complicated, and made the final call on what shipped.

## What I learned

- Writing clear, specific requirements gets far better AI output than vague prompts.
- AI-generated code still needs review: knowing when to trust it and when to intervene is the real skill.
